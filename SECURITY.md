## Security

Please report any security issue to [security@salesforce.com](mailto:security@salesforce.com)
as soon as it is discovered. This project limits its runtime dependencies in
order to reduce the total cost of ownership as much as can be, but all consumers
should remain vigilant and have their security stakeholders review all third-party
products (3PP) like this one and their dependencies.

When reporting a vulnerability, please include the following details where possible:

- A description of the issue and its potential impact.
- Steps to reproduce or proof-of-concept code.
- The affected version(s) (commit SHA or release tag).
- Any suggested mitigations or fixes.

Please **do not** open a public GitHub issue for security-sensitive reports.
